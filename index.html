1. The Threat Landscape: Attack Tools

Knowledge of common free tools is our first line of defense. Below is how they are weaponized:

Tool Fraudulent Use Defense
Web Browser OSINT & Site Cloning Verify URLs, check SSL certificates.
Thunderbird Spoofing Identities Flag [EXTERNAL] email headers.
ExifTool Metadata Scraped from PDF/JPG Scrub files before sharing.
Audacity Cleaning Audio for Voice Clones Use Safe Word verification protocol.

2. Employee STOP Protocol

SOP-SEC-01: Incident Identification

  • S - SKEPTICISM: Spot red flags like urgency or odd phrasing.
  • T - TRACE: Verify identity via a secondary channel (Slack/Known Phone).
  • O - OBSTRUCT: Do not click links or share credentials.
  • P - PREVENT: Report the attempt to IT Security immediately.

3. Executive Safe Word Protocol

Protocol: Challenge any voice-based financial request with a pre-set secret question. No correct Safe Word = No Action taken.

Challenge Examples

  • "What was the team's Q3 project color code?"
  • "What is the designated safe city for this month?"

4. IT/Admin Response Checklist

  • [ ] Isolate: Purge suspicious email from all inboxes.
  • [ ] Monitor: Review logs for "Impossible Travel" logins.
  • [ ] Remediate: Force password resets if credentials were exposed.
  • [ ] Block: Blacklist sender IPs and Domains.
